# Architecture

## Overview
High-performance fullstack web application template built with Next.js App Router, tRPC, React 19, Tailwind CSS, and Drizzle ORM.

## Directory Structure
- \src/app/\: Next.js App Router pages and client components
- \src/server/api/\: tRPC router definitions, procedures, and context
- \src/server/db/\: Drizzle database schema, connections, and migrations
- \src/trpc/\: Client and server tRPC hooks and callers
- \docs/\: Architecture, specifications, plans, and architectural decisions
